# Practical 1: Algorithm Analysis and Performance Comparison

This practical contains three Python programs that compare the performance of different algorithms using randomly generated data.

## Files Included

- Lab1_Q1_BinarySearch.py - Compares Linear Search and Binary Search.
- Lab1_Q2_BubbleMergeSort.py - Compares Bubble Sort and Merge Sort.
- Lab1_Q3_PrimeGeneration.py - Compares different prime generation methods.
- Lab1_Q1_Screenshot.md, Lab1_Q2_Screenshot.md, Lab1_Q3_Screenshot.md - Brief screenshot notes for each question.

## What Each Program Does

1. Binary Search Comparison
   - Implements Linear Search and Binary Search.
   - Measures average execution time for increasing input sizes.

2. Sorting Comparison
   - Implements Bubble Sort and Merge Sort.
   - Measures average execution time for different array sizes.

3. Prime Generation Comparison
   - Implements naive trial division, optimized trial division, and the Sieve of Eratosthenes.
   - Measures execution time for different limits.

## How to Run

Run each script using Python 3:

```bash
python3 Lab1_Q1_BinarySearch.py
python3 Lab1_Q2_BubbleMergeSort.py
python3 Lab1_Q3_PrimeGeneration.py
```
